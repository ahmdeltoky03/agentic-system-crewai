## Agentic Framework with CrewAI

A progressive learning journey building AI Agent systems using [CrewAI](https://crewai.com) — starting from single-agent workflows all the way up to a fully orchestrated multi-agent system.

---

### Financial Researcher
An educational project demonstrating an Agentic AI system using CrewAI focused on a Financial Researcher agent.  
It showcases how an AI agent can analyze financial data, generate insights, and support decision-making.  
Built to explore agent-driven research workflows and financial analysis using LLMs.

---

### Coder
An educational project demonstrating an Agentic AI system using CrewAI focused on a Coder agent.  
It showcases how an AI agent can generate, optimize, and automate coding tasks.  
Built to explore agent-based development workflows and code generation using LLMs.

---

### Sports Analytics Platform
A production-grade capstone project that brings everything together in a fully orchestrated **Multi-Agent System**.  
6 specialized AI agents collaborate to analyze world football — covering players, teams, matches, and competitions across all major European leagues.  
Accepts natural language questions in Arabic or English and delivers professional analytics reports in Markdown, JSON, and PDF.

---

>  **Journey:** Single Agent → Multi-Agent System  
> From one agent handling everything, to multi-agent specialized agents working in coordination — each with a dedicated role, tools, and context awareness.
