## Agentic Framework with CrewAI (Educational Projects)


### Financial Researcher 
An educational project demonstrating an Agentic AI system using CrewAI focused on a Financial Researcher agent.  
It showcases how an AI agent can analyze financial data, generate insights, and support decision-making.  
Built to explore agent-driven research workflows and financial analysis using LLMs.

### Coder 
An educational project demonstrating an Agentic AI system using CrewAI focused on a Coder agent.  
It showcases how an AI agent can generate, optimize, and automate coding tasks.  
Built to explore agent-based development workflows and code generation using LLMs.
